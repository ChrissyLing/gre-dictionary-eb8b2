# 例句译文的来源和质量标识

优先级：已逐句校对的条目 → 原资料已提供的译文 → 用户点击后获取的机器参考译文。查词和浏览例句不会自动请求翻译服务。

`data/reviewed-translations-v1.json` 保存 22 条校对译文和 2 条原句存疑记录；页面内嵌相同数据。修改时须同步三个当前 HTML 入口。校对覆盖当前这批具体例句，不表示全部例句已经核对。

葡萄酒例句中的 cloudy 按酒液浑浊理解，opaque 为不透光，pour it 为倒酒。显示校对后的中文和词义说明，不再使用机译的“多云”“倾倒”。

原书译文标明来源及 PDF 页码。原书来源不代表已另外校对。现有 zw3000 补充例句已提供的中文继续保留。

机器结果一律标注“机器参考译文 · 未校对”，不能升级为已校对状态。机器缓存只在当前页面会话内使用；校对记录始终优先于机器缓存。翻译失败支持重试。已知原句语意或搭配存疑时暂停翻译并解释原因，避免用流畅中文掩盖原句问题。

“译文有误”链接仅打开带原句、当前译文、译文类型和页面地址的 GitHub 纠错表单，读者需登录后自行提交；网站不会自动创建 Issue 或发送消息。反馈不是自动修正，维护者仍需结合英文语境核对后更新校对词库。

验证：`node tests/lookup.cjs` 检查校对和原书译文优先、已知错译修复、源句问题标记、未校对标签、机器缓存、HTML 转义和预填纠错链接。`tests/translations.cjs` 使用 Playwright + Chrome 与模拟翻译接口检查真实页面，确保浏览例句不发出翻译请求，只有用户点击才获取机器译文，并检查手机布局。测试不会访问真实翻译接口或提交反馈。
