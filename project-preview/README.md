## 环境配置

- 环境：`gre-dictionary-test-d9b907d008e0`，上海 PostgreSQL。
- `cloudbase-config.json` 的 `enabled` 已设为 `true` 供测试；正式开放前必须完成下方真实验证。
- 在 CloudBase 身份认证中开启邮箱验证码，配置云开发邮件服务。
- 获取 **Publishable Key**，填入 `publishableKey`。此处禁止使用 SecretKey、API Key 或 service_role 密钥。
- 将实际测试站点域名加入身份认证安全域名；本项目使用 GitHub Pages 时为 `chrissyling.github.io`。
- 在这个测试环境的 SQL 编辑器运行 [schema-v1.sql](backend/schema-v1.sql)。仅创建两张新表和相应权限，不修改原字典资料。
- 当前入口为测试用途；未通过双账号验证前不要作为正式服务宣传。

## 开放给其他用户前的必要验证

1. 用两个独立邮箱创建 A、B 账号，分别添加不同收藏；切换账号、刷新、重新登录后互不可见。
2. 同一账号在另一设备登录能看到收藏和复习记录；删除后另一设备同步不会恢复被删词。
3. 用 A 的登录令牌请求 B 的 owner_id，只能得到空结果；伪造 B 的 owner_id 写入必须失败。匿名请求不得读取表。
4. 离线修改后上线同步；同步失败仍保留本机待上传操作。不要在未同步时清除浏览器数据。
5. 邮箱验证码错误、过期、重新发送、退出登录和刷新会话均有真实测试。
6. 用中国大陆与海外网络各测试一次，确认邮件和 API 可访问。免费套餐额度与到期时间以控制台为准。

测试没有完成前，不宣称云端账号可用。前端测试不能代替真实服务上的行级权限验证。

## 版本与数据约定

- `releases/0.1.0/` 包含冻结的应用、查词引擎与数据副本。首次发布后不覆盖这些文件。
- 后续版本建立新的 `releases/x.y.z/`；只更新 `releases.json` 目录。用户首次进入选默认版本，之后固定其选择；已选版本缺失时显示错误，不自动升级。
- 收藏与复习使用稳定 v1 数据格式，独立于应用版本。数据库变更只做兼容性新增。
- 每个账号使用独立本机空间；旧站点的 `greDictFav` 只在用户主动点击“导入”后复制。
- 收藏删除以 `favorite:false` 墓碑同步；不会自动整表覆盖。
- 本机体验不模拟登录，也不声称已云端同步。
- 当前同步采用服务端写入先后顺序；同一个词在多台设备离线编辑时，最后完成的上传会覆盖该词的旧记录。它尚不是多人实时协作系统。

## 0.1.1：密码登录

CloudBase「身份认证 → 登录方式」需开启「用户名密码」。支持邮箱或已绑定用户名配合密码登录；新用户先用邮箱验证码创建账号。已有账号选择「首次设置密码 / 忘记密码」，使用原邮箱获取重置验证码，再设置密码；登录后也可在「我的账号 → 设置 / 重置密码」操作。

使用官方 SDK `signInWithPassword`、`resetPasswordForEmail` 及其 `data.updateUser({nonce,password})` 闭包。没有使用普通 `updateUser` 修改密码，也不会在 localStorage 或个人收藏表存储密码。密码错误、验证码错误等验证结果由 CloudBase 认证服务决定。

旧用户继续使用 0.1.0；在「版本」中主动切换到 0.1.1。新版本沿用相同账号 ID 与 v1 收藏/复习表。新增测试 `tests/password-provider.mjs` 和 `tests/password-browser.cjs`，覆盖 SDK 参数、挑战绑定、密码登录和重置、重新登录、原有收藏保留及验证码入口回归。浏览器密码流程用模拟服务验证；真实密码设置和登录需由账号持有人完成，不向维护者发送密码或验证码。

## 0.1.2：短信登录与绑定

登录页增加短信验证码，输入中国大陆 11 位手机号会规范为 +86，其他国家输入 +国家码。密码入口也支持绑定的手机号。短信发送只在用户点击后调用，界面有 60 秒重发倒计时。服务器端限制仍由 CloudBase 实施。

已有邮箱账号应先用原邮箱登录，在「我的账号 → 绑定 / 更换手机号」使用验证码绑定；随后短信登录继续使用同一用户 ID。服务若提示号码已绑定其他账号，不会自动迁移或合并收藏。直接用未绑定手机号注册可能创建另一账号，页面已提示。仅手机号账号登录后通过 `reauthenticate` 验证手机来设置密码，未将手机号错误传给邮箱专用重置接口。

手机号绑定调用官方 `auth.updateUser({phone})`，再调用返回的 `data.verifyOtp({phone,token})`；独立短信登录调用 `signInWithOtp({phone})` 返回的 `verifyOtp({token})`。绑定挑战跟踪原用户 ID、目标手机号与取消代数，账号切换或关闭后的挑战不会继续应用。

新增 `tests/sms-provider.mjs`、`tests/sms-browser.cjs`。本地模拟测试验证手机号规范、验证码与账号绑定、跨账号拒绝、取消、发码倒计时、原收藏保留及邮箱/密码回归。真实短信送达和真实手机号绑定需账号持有人在自己的设备上测试，不向维护者发送验证码。

## 0.2.0：V / Q 分区与数学专题

V 语文保留原词典、等价词、收藏、复习和全部登录方式。Q 数学独立目录按 26 个实际有题的知识专题组织，支持来源、难度、关键词组合筛选；详情页可返回筛选与列表位置，浏览器后退/前进可用。Q 当前提供浏览原题和原资料已有解析，不新增数学做题记录数据库表。

导入数学900题900条、回忆机经360条、170难题169道实际数学题，以及满分宝典564道编号练习/模考题，共1993道。满分宝典另有专题教材原页；五套模考各40题。原书170难题第170条是词汇自查提示，未计作数学题。900题原表Easy/Medium/Hard保留；图表题及没有逐题分级的其他资料标注整理初评。难题集的“挑战”依据资料定位，不能解读为ETS官方难度。参考评级基于知识点、题干条件和复杂度，尚未用考生作答统计校准。

图片保留源页原样，题号定位裁窗用于阅读；跨页、共享图表和复杂图形可展开完整相邻原页。OCR/原PDF文字仅用于检索与初步分类，原题图像优先。没有在题目正文附带答案的来源显示未附解析，不生成假答案。满分宝典双语练习可展开右栏说明，模考可按原资料整套解析页查阅。

题图按4页打包并懒加载，以减少导入文件数；浏览题目时仅请求涉及的小包。新发布版本冻结本次资料快照，不覆盖旧版数据。
