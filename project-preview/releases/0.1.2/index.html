验证原账号后设置新密码，收藏和复习记录仍属于同一个账号。仅手机号账号请先用短信登录，再设置密码。

至少 8 位，建议包含字母和数字；还需符合账号服务的密码强度要求。

将手机号绑定到当前账号，之后可用短信登录同一账号。若该号码已注册为另一账号，不能自动合并数据。

每个账号只同步自己的学习数据。本机已有收藏不会自动上传，需你主动选择导入。
