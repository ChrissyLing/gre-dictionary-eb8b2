# 常见中文义项词群

入口位于“中文→英文”之后的“常见等价词”，可用 `#groups` 直达。

当前人工整理 80 类义项、1065 个不同英文词。目录区域最大宽度为 1160px；桌面使用两列留有 20px 间距的长方形卡片，手机为一列。卡片完整区域可点击，显示义项名称、相关词对考频合计、词数和子义项数。全部 80 类卡片按考频加和降序排列，可通过中文或英文筛选。

目录（`#groups`）、独立词群页面（`#groups/<id>`）和单词页面（`#<word>`）是三层视图。点击卡片进入仅含对应词群内容的独立页面，不在长目录下面展开。返回目录保留筛选和滚动位置；词条返回词群也保留详情展开状态和位置，支持浏览器前进后退。共享的词群直达链接可单独打开并返回目录。所有视图仍由同一静态 HTML 提供，适用于 GitHub Pages 的仓库子路径。

`data/meaning-groups-v1.json` 保存词群、细分义项、来源原文和资料直接列出的词对；页面内嵌同一数据。排序在运行时使用现有 `SE_PAIR_FREQ`，不改原始词对考频。修改功能需同步三个当前 HTML 入口。

## 考频加和规则

- 以无方向的原表词对为去重单位。同一词对多来源重复或 a→b / b→a 两个方向只计一次。
- 词群考频合计：该词群中所有不同原表词对考频之和。不会通过相加两端单词的分数来计算，因此不会把同一词对重复计算。
- 词旁数字：该词在本词群中参与的所有不同原表词对的考频之和。如 acerbic–vitriolic 13 次、acerbic–harsh 6 次，acerbic 显示 19。
- 子义项排序：涉及该子义项任一词的去重原表词对考频加和；一个词对在同一子义项中只计一次。不将各子义项分数相加推算整个词群。
- 原表复数等词形通过无歧义的简单还原匹配已人工分组的原形。展开词对仍保留原表词形和原始考频，如 encomiums/tributes 的 17 次。
- 没有考频记录的置后，同分保留原顺序。原表词对展开列表仍按单个词对原始考频降序排列。
- 该合计是词对考频的加和，不代表去重后的真题题数。原始来源为学而思；不使用已收录例句数作为考频。

## 分组与来源

分组为具体词义的学习索引，不代表组内所有词可以无条件互换，也不声称穷尽英语全部同义词。词性、语气、搭配和动作方式分别标明。不使用同义词图的传递闭包；不按简单中文子串自动入组，避免把“不可避免”归入“阻止”。

来源包括急救1400词、青山答案词、zw 镇考机经词7.0、zw 阅读机经核心词汇、zw 镇考3000词、zw 等价词、已收录六选二记录和站内基础词典。来源原文可能包含该词其他义项。真题、模拟和 zw 参考表的标签分别保留。

## 返回和词对展示

词群页面内直接以 a ↔ b 显示资料明确列出的词对，不只藏在详情中。箭头仅使用直接配对记录；跨子义项配对单独列出。词对旁显示该对原表考频，未配对的其余词保持无边框的可点击文字。

目录、词群详情、单词详情使用浏览器 history 状态导航。离开时保存内存快照，包括 DOM、筛选、details 展开状态和滚动位置。恢复时递增请求序号，避免未完成查询覆盖返回界面。词条的返回按钮和模式按钮返回来源词群；词群的返回按钮返回来源目录。独立词群链接没有来源快照时，也能返回完整目录。

## 验证

`node tests/lookup.cjs` 检查 1065 个词的可查性、来源、考频去重加和、排序和语义边界。`tests/navigation.cjs` 使用 Playwright + Chrome 覆盖整张卡片点击、两列/单列宽度与间距、独立词群页面、三层 Back/Forward、精确恢复筛选/滚动/展开、清除筛选、共享链接打开及返回、手机无横向滚动。`tests/translations.cjs` 回归核对原书/校对译文优先与机器译文标识。测试使用本地文件与模拟接口，不提交反馈。
